Problem: Lexicographical Frequency-Based Optimal BST
Description:
Given:
* A list of keywords: keywords = ["do", "else", "if", "while"]
* A corresponding list of frequencies: frequency = [5%, 40%, 10%, 30%]
Each keyword is used with a known frequency (as a percentage). You are to construct a Binary Search Tree (BST) such that:
1. BST Property is maintained based on lexicographic ordering of keywords.
2. The cost of the BST is minimized.
3. The cost function is defined as:
For every keyword in the BST, Cost += depth_of_node * (frequency / 100) where the root has depth = 1, its children have depth = 2, and so on.
Objective:
Return the structure of the BST that yields the minimal total cost.
Constraints:
* All keywords are distinct.
* Frequencies are percentages summing up to 100.
* Keywords are inserted into the BST while maintaining lexicographical order.

🔢 Example:
Input:
java
CopyEdit
keywords = ["do", "else", "if", "while"]
frequency = [5, 40, 10, 30] // interpreted as percentages
Expected Output: A BST structure (text or object form) with minimal cost, e.g.,
arduino
CopyEdit
       else
      /    \
    do      while
             /
           if
Cost:
* else (depth 1) → 40 × 1 = 40
* do (depth 2) → 5 × 2 = 10
* while (depth 2) → 30 × 2 = 60
* if (depth 3) → 10 × 3 = 30 Total Cost = 140

✅ Your Task:
Implement a function that:
* Accepts the keyword list and frequency list.
* Returns a minimal cost BST (structure or preorder traversal).
* Calculates and prints the minimal total cost.
